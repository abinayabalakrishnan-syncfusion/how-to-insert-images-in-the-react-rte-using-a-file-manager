# How to Insert Images in React RTE Using a File Browser

**Repository Description**  
This repository contains a **quick‑start React sample** that demonstrates how to **browse images from a cloud source and insert them into the Syncfusion React Rich Text Editor (RTE)** using a **File Manager / File Browser**.

The sample shows how file‑browsing functionality can be integrated with the Rich Text Editor to allow users to select image files and embed them directly into editor content.

## Project Overview
The purpose of this project is to help developers understand how to configure the Syncfusion React Rich Text Editor with file‑browser support. It provides a reference implementation for enabling image insertion workflows in React applications using Syncfusion UI components.

## Features
- Integration of **Syncfusion React Rich Text Editor**
- Image browsing using a **File Browser / File Manager**
- Insert selected images directly into editor content
- React‑based setup suitable for quick prototyping
- Cloud‑based image browsing support

## Prerequisites
Ensure the following requirements are met before running this project:
- Latest version of **Node.js**
- **Visual Studio Code**
- Basic knowledge of React

## Installation

### Clone the Repository
Clone the repository and navigate to the project directory:

```bash
git clone https://github.com/SyncfusionExamples/how-to-insert-images-in-the-react-rte-using-a-file-manager
cd how-to-insert-images-in-the-react-rte-using-a-file-manager
```
### Install Dependencies
Install the required React packages using:
```bash
npm install
```
### Running the Application
Start the React development server with the following command:
```bash
npm start
```
After the server starts, open the URL shown in the terminal (typically http://localhost:3000) to view the application.

### Configuration
The file browser integration is configured within the React component setup. You can customize:
- File source locations
- Accepted image formats
- File browser behavior
- Rich Text Editor toolbar options
